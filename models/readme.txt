PURPOSE & OVERVIEW
------------------
This folder stores pre-trained model weights, fine-tuned network weights, and 
target checkpoints used for live inference in the backend.


- finetuned/
  Subdirectory containing models explicitly fine-tuned for LIVEDET, including 
  the 'pothole_detector_yolo11s_v22' checkpoint which achieved peak performance 
  on the clean merged dataset.
