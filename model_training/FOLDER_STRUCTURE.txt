MODEL STORAGE STRUCTURE
=======================

Folder Organization in `runs/`
--------------------------------------------------

runs/
└── base_models/                        ← BASE & FINE-TUNED TRAINING RUNS
    ├── yolov8s_fresh2/                 ← YOLOv8s Baseline Run
    │   ├── weights/
    │   │   ├── best.pt                 ← Baseline YOLOv8s Checkpoint
    │   │   └── last.pt
    │   ├── results.csv                 ← Training Metrics History
    │   └── args.yaml                   ← Run Configuration Parameters
    │
    ├── pothole_detector_yolo11s/        ← YOLO11s Baseline Run
    │   ├── weights/
    │   │   ├── best.pt                 ← Baseline YOLO11s Checkpoint
    │   │   └── last.pt
    │   ├── results.csv
    │   └── args.yaml
    │
    ├── pothole_detector_yolo11s_v22/    ← Production Champion Fine-Tuning Run
    │   ├── weights/
    │   │   ├── best.pt                 ← ✓ Active Production Champion Checkpoint
    │   │   └── last.pt
    │   ├── results.csv
    │   └── args.yaml
    │
    └── pothole_yolo11s_autotune_r12/   ← Autotuning Hyperparameter Run
        ├── weights/
        │   ├── best.pt
        │   └── last.pt
        ├── results.csv
        └── args.yaml

--------------------------------------------------

Usage Pattern
--------------------------------------------------

=== Stage 1: Base Baseline Training ===
Train baseline models on `mydataset` configuration:
```bash
python model_training/train_unified.py
```
Output directory: `runs/base_models/pothole_detector_yolo11s/`

=== Stage 2: Champion Fine-Tuning ===
Fine-tune the model with custom parameters (cosine learning rate, backbone freezing, imgsz scaling) on `mydataset`:
```bash
python model_training/fine_tune.py
```
Output directory: `runs/base_models/pothole_detector_yolo11s_v22/`

=== Stage 3: Deployment ===
To deploy the champion model, configure the path in the `.env` file:
```env
BEST_MODEL_PATH=./models/finetuned/pothole_detector_yolo11s_v22/weights/best.pt
```

--------------------------------------------------

Key Points
--------------------------------------------------

1. **Unified Storage Directory** - All model runs are stored under `runs/base_models/` for structured organization.
2. **Autotuning Runs** - Auto-parameter sweeps are located in `runs/base_models/pothole_yolo11s_autotune_r*/` to keep sweeps separate from main runs.
3. **Checkpoints** - Always use `best.pt` for deployment and inference, and use `last.pt` only if resuming interrupted training.
