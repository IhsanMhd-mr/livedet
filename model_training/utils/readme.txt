PURPOSE & OVERVIEW
------------------
This package contains utility modules for processing labels, estimating depth, 
and computing severity matrices for the LIVEDET pothole detection system.

MODULES
-------
1. depthestimator.py
   Estimates physical dimensions of potholes from bounding box pixels mapping.

2. severitycalculator.py
   Calculates severity scores and generates vehicle-specific hazard warnings.

3. datasethandler.py
   Manages YOLO dataset organization, formatting, and yaml generation.
