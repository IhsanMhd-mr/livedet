Live Detection Frontend Guide

Project Structure:
- src/pages/LiveDetection.jsx: Real-time detection page featuring WebRTC/canvas rendering, ADAS audio alerts, and collision settings.
- src/pages/ImageDetection.jsx: Static image upload page with interactive dimension tables.
- src/pages/VideoDetection.jsx: Offline video upload processing and playback page.
- src/pages/Home.jsx: Dashboard landing page.
- src/hooks/useWebSocket.js: Manages socket connections, reconnect attempts, and event streaming.
- src/components/ui: Stylized glassmorphic interface cards, loader symbols, and status badges.
